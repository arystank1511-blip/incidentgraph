# IncidentGraph

Incident investigation for distributed systems: correlated telemetry, service dependency graphs, and explainable, deterministic root cause ranking.

**Repository owner and maintainer: [Arystan Kabdesh](https://github.com/arystank1511-blip).**

## Project at a glance

- Full-stack portfolio MVP with Next.js, React, TypeScript, NestJS, PostgreSQL, Prisma, and optional Redis
- Incident timelines, logs, metrics, trace waterfalls, and dependency graph exploration
- Reproducible synthetic telemetry; no live production monitoring or claimed machine-learning model
- Unit, integration, and browser test suites included in the source archive

## Source and local setup

The original source snapshot is available in [incidentgraph-main.zip](incidentgraph-main.zip). Extract the archive, then follow its README for setup and test commands. A source-tree restoration and verification update is being prepared as a pull request so the code can be browsed and reviewed directly on GitHub.
